# Product Charter — Ascendant-Product

## Vision
Build a polished public RPG-style CV that communicates real professional capabilities by exploration rather than conventional resume sections.

## Audience and purpose
- Recruiters and technical decision makers seeking Senior .NET / Azure / DevOps skills.
- Creator: portfolio, creative AI-assisted development experiment, demonstrable Azure/GitHub/Terraform delivery capability.

## Character and accuracy rules
- Character = owner, eventually personal portrait/avatar, but **not during current phase**.
- Role labels: **Senior .NET / Azure Developer / DevOps Engineer**; do NOT position as Cloud Architect.
- Showcase truthful projects, technologies, experience and achievements; no fictional certifications or work history.
- Visual identity must be original; no direct imitation of Path of Exile 2 or Clair Obscur: Expedition 33.

## MVP functional scope (after infrastructure)
- Landing/character identity panel.
- Skill/stat categories tied to evidence, not arbitrary claims.
- Career quest/history chapters.
- Selected project achievements and external contact/CV links.
- Responsive, accessible, performant static site.

## Explicit non-goals
- No backend/API/database/auth/account system at launch.
- No multiplayer, game mechanics, procedurally generated RPG world, paid monetization.
- No prototype/staging Azure environment. Production only.
- No UI design/assets implementation before infrastructure delivery.

## Product outcomes
- A public HTTPS URL displays the deployed application.
- A merged change to main results in validated production deployment.
- User can maintain profile content without redeploying infrastructure.

## Constraints
Keep spending minimal; no undisclosed paid Azure resources. Production deploys must be gated by CI and security checks; tests refer to checks, not separate environments.
